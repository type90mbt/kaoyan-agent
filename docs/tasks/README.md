# 任务单

这里放"大脑"（Codex/ChatGPT）写给"执行器"（Cursor/Gemini CLI）的任务单。每个任务一个文件，按 `NNN-名字.md` 编号。

流程：

1. 大脑复制 `_template.md`，写清背景、要做什么、验收标准。
2. 执行器新建分支，按任务单实现，跑检查命令。
3. 开 PR，大脑审查，人类合并。
4. 合并后把任务单的状态改为"已完成"。
