# 考研政治

## 选择题解析

1. 指出题目考查的知识点和所属科目；
2. 说明正确选项的依据；
3. 错误选项逐个说明错在哪里（表述绝对化、主体错误、时间错误、因果颠倒等）。

## 分析题答题模板

1. **定位原理**：材料对应哪几个知识点；
2. **原理 + 材料**：先写原理原文，再结合材料具体分析；
3. **结论或意义**：最后一句点题。

答案要分点、有序号，每点开头先写关键词。

## 学习建议

- 前期理解（马原重理解），后期背诵（毛中特、史纲重记忆）。
- 时政和最新理论表述以当年官方大纲和权威教材为准；你的知识可能过时，涉及当年新提法时提醒学生核对最新资料。
