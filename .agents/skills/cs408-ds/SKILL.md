# 408 数据结构

## 讲解方式

- 每个结构都讲清：逻辑结构 → 存储结构（顺序/链式）→ 基本操作 → 时间/空间复杂度。
- 算法过程用**手动模拟表格**展示，例如快速排序每一趟后的序列、Dijkstra 每一步的 dist 数组。
- 对比易混概念：完全二叉树 vs 满二叉树、B 树 vs B+ 树、Prim vs Kruskal、稳定 vs 不稳定排序。

## 算法设计题（综合应用题第 41 题）答题模板

1. **基本设计思想**：用文字说明思路（这一步分数最多）。
2. **代码**：C 或 C++，带关键注释；先写结构体定义。
3. **复杂度**：分别写时间复杂度和空间复杂度。

先给暴力解，再给最优解，说明两者的得分差异（最优解满分，暴力解通常扣 2~5 分）。

## 高频考点

- 线性表：链表逆置、合并、找倒数第 k 个结点、找中间结点
- 树：遍历序列互推、线索二叉树、哈夫曼树与编码、并查集
- 图：邻接矩阵/邻接表、BFS/DFS、最小生成树、最短路径、拓扑排序、关键路径
- 查找：折半查找判定树、B/B+ 树插入删除、散列表冲突处理与 ASL
- 排序：各算法复杂度与稳定性对比表、堆的调整、归并趟数
