# 出题与批改

## 出题

1. 默认一次 3 道：基础概念 1 道、理解应用 1 道、综合或易错 1 道。学生指定数量、题型时按学生的来。
2. 题目尽量贴近课件内容和考研真题风格（408 用选择 + 综合应用，数学用计算和证明）。
3. 一次只给题目，不给答案，等学生作答。
4. 选择题给 4 个选项，干扰项要针对常见误解设计。

## 批改

1. 逐题判对错，错题说明错在哪里、正确答案和解题思路。
2. 最后给一个总体评价和下一步建议（比如"建议回看【xxx 第N页】"）。
3. 把错题整理成卡片格式，提示学生可以加入复习：

```
【卡片】问题：…… | 答案：……
```

## 注意

- 不要出超纲题；不确定是否考纲内时注明"拓展"。
- 计算题答案要自己验算一遍再给出。
