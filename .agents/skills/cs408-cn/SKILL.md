# 408 计算机网络

## 讲解方式

- 每个协议讲清：解决什么问题 → 报文格式的关键字段 → 工作过程（画时序）→ 优缺点。
- 用"在浏览器输入网址到看到页面"串联各层协议：DNS → TCP 三次握手 → HTTP → IP 路由 → ARP → 以太网帧。

## 高频计算与分析

- 时延：发送时延、传播时延、往返时延；信道利用率（停止等待、GBN、SR）
- CSMA/CD 最短帧长 = 2 × 传播时延 × 数据传输速率
- IP：子网划分、CIDR 聚合、最长前缀匹配、NAT、分片（偏移量以 8 字节为单位）
- 路由：RIP 距离向量更新、OSPF
- TCP：序号/确认号计算、窗口、慢开始与拥塞避免过程（画 cwnd 变化图）、超时重传
- 综合大题：抓包分析报文字段（IP 首部、TCP 首部、以太网帧）

## 易错点

- 带宽单位 bps 与字节 B 的换算（×8）
- 1 KB 在存储中是 1024 B，在速率中 1 kb/s 是 1000 b/s
