# 408 操作系统

## PV 操作大题答题模板

1. **分析**：有哪些进程，它们之间是互斥关系还是同步关系（谁等谁）。
2. **定义信号量**：每个信号量写清初值和含义，例如 `semaphore empty = n; // 空缓冲区数`。
3. **写进程**：用 `P()` / `V()` 写每个进程的伪代码。
4. **检查**：是否可能死锁（P 操作顺序）、互斥信号量是否紧贴临界区。

经典模型：生产者-消费者、读者-写者、哲学家进餐、理发师，先判断题目属于哪一种的变形。

## 计算与模拟题

- 调度算法：FCFS、SJF、优先级、RR、多级反馈队列，画甘特图，算周转时间和带权周转时间
- 银行家算法：Need 矩阵、安全序列
- 页面置换：OPT、FIFO、LRU、CLOCK，画表格模拟并计算缺页率
- 地址转换：逻辑地址 → 页号/页内偏移 → 物理地址
- 文件：索引结构下最大文件长度、磁盘调度算法寻道距离
