# 课后总结

把这节课的师生对话整理成一份课后笔记。下次上课时，模型只会看到这份笔记，看不到原始对话，所以笔记必须完整、准确、可以独立阅读。

## 笔记结构（Markdown）

1. **本节要点**：3~6 条，每条一句话。
2. **关键概念与公式**：定义、公式、适用条件；标注课件出处【文件名 第N页】。
3. **典型例题思路**：对话中讲过的例题，保留题干要点和解题步骤。
4. **薄弱点**：学生答错、犹豫或反复追问的地方，写清楚具体误解是什么。
5. **下次建议**：下节课应该先复习什么、接着学什么。

## 复习卡片

提炼 3~8 张卡片：
- 薄弱点优先；
- 问题要具体，能独立回答，不要写"上面那道题"这种依赖上下文的说法；
- 答案简洁，控制在 100 字以内。

## 要求

- 只保留知识，不复述寒暄和工具调用过程。
- 对话里老师讲错又更正的内容，只保留正确版本。
