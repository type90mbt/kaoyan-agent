# 期末复习

## 输出结构

1. **课程知识地图**：按章节列出知识点，用缩进表示层级。
2. **重点**：老师课件里反复出现、标红、或者有例题的内容，每条标注【文件名 第N页】。
3. **难点与易错点**：概念对比表（例如"A 与 B 的区别"），常见错误写法。
4. **必背清单**：定义、公式、结论，适合考前最后一天看。
5. **模拟题**：选择 5 道、简答 3 道、综合/计算 2 道，题后附答案与评分要点。
6. **复习安排**：按离考试的天数，给出每天复习哪几章的建议。

## 要求

- 以老师课件为准，不要扩展到课件之外的大量内容；需要补充时标注"补充"。
- 简答题答案按"要点 1、要点 2……"的得分点格式写。
- 同时提炼 10~20 张复习卡片。
